# MOKO_ExDriver

Проект, предоставляющий "внешние" или "расширенные" драйверы для платформы MOKO SE. Содержит реализации как на Python, так и на LabVIEW.

## Описание

Этот репозиторий служит дополнением к основной библиотеке драйверов. Он включает в себя:

- **Python-драйверы:** Набор `.py` файлов, которые инкапсулируют логику управления различным оборудованием (APPA207, BK1697B, FY6900) или реализуют общие протоколы (SCPI). `ExDriver.py` служит примером или базовым классом для создания новых драйверов.
- **LabVIEW-проект:** Проект `.lvproj`, который, вероятно, объединяет эти драйверы для использования в среде LabVIEW.

Основная идея заключается в том, чтобы предоставить унифицированный интерфейс для управления оборудованием из скриптов MOKO SE с помощью команды `MOKO.Driver()`.

## Структура проекта

- **exPythonDocs/**: Папка с Python-реализациями драйверов.
  - `ExDriver.py`: Пример или шаблон внешнего драйвера.
  - `APPA207.py`, `BK1697B.py`, `FY6900.py`: Драйверы для конкретных приборов.
  - `SCPI.py`, `ZNA43.py`: Драйверы, основанные на стандартных протоколах.
- **MOKO ExDriver.lvproj**: Файл проекта LabVIEW для интеграции драйверов.

## Ключевые технологии

- Python
- LabVIEW
